# John Design WordPress

Dépôt public de distribution de **John Design Core** et du thème **John Design Studio**.

Ce dépôt alimente les mises à jour automatiques du site WordPress John Design.

- Plugin : John Design Core
- Thème : John Design Studio
- Canal : production
- Aucun mot de passe, jeton WordPress ou secret n'est stocké ici.

## Distribution

- `dist/johndesign-core.zip` : paquet du plugin
- `dist/johndesign-studio.zip` : paquet du thème
- `updates/johndesign-core.json` : manifeste plugin
- `updates/johndesign-studio.json` : manifeste thème

Les versions sont publiées et maintenues depuis ChatGPT via le connecteur GitHub autorisé.
